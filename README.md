# LinkedIn Post Extractor Extension

Browser extension designed to extract LinkedIn posts by company and individual profiles to support analysis, tracking, and marketing workflows.

**Created:** 2023

## Overview

This extension automates the extraction of LinkedIn posts directly from company pages and personal profiles. It enables structured data collection for content analysis, engagement tracking, and outbound strategy support.

The tool interacts with LinkedIn’s DOM to capture post-level data and transform it into usable datasets.

## Features

- Extract posts from company pages
- Extract posts from individual profiles
- Capture post content, timestamps, and engagement metrics
- Automate scrolling and data collection
- Prepare data for export and analysis

## Tech Stack

- JavaScript (Vanilla)
- HTML
- CSS
- Chrome Extension APIs
